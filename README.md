# Digital Gravity Website
A modern, responsive clone of the Digital Gravity website built with HTML, CSS, and JavaScript.

## Features

- 🎨 Modern, sleek design with gradient effects
- 📱 Fully responsive layout for all devices
- ✨ Smooth animations and transitions
- 🎯 Interactive navigation with scroll effects
- 📧 Contact form with validation
- 🚀 Fast and lightweight

## Sections

1. **Hero Section** - Eye-catching landing area with call-to-action buttons
2. **Services** - Showcase of digital services offered
3. **About** - Company information and statistics
4. **Portfolio** - Grid display of projects and work
5. **Contact** - Contact information and form
6. **Footer** - Links and social media

## Getting Started

1. Open `index.html` in your web browser
2. No build process or dependencies required - it's pure HTML, CSS, and JavaScript!

## File Structure

```
digitalgravity-clone/
├── index.html      # Main HTML file
├── styles.css      # All styling and responsive design
├── script.js       # Interactive functionality
└── README.md       # This file
```

## Customization

- **Colors**: Edit the CSS variables in `styles.css` (root section)
- **Content**: Modify the HTML in `index.html`
- **Animations**: Adjust JavaScript in `script.js`
